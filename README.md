# C# & Software Engineering Learning

A repository dedicated to developing practical skills in C#, modern .NET, and software engineering.

## About

This repository documents my learning journey toward becoming a proficient software engineer specializing in C# and the .NET ecosystem.

Although I have a Computer Science degree and professional experience in software development, my goal is to strengthen my fundamentals, improve problem-solving and debugging skills, and build more complex systems independently.

## Learning Goals

- Strengthen C# fundamentals and object-oriented programming.
- Master modern C# and ASP.NET Core.
- Improve debugging, testing, and code comprehension.
- Study software architecture and design principles.
- Develop practical projects using .NET, SQL Server, and related technologies.
- Build confidence in designing, implementing, and maintaining software independently.
