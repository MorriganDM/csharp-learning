# Agent Instructions

This repository is dedicated to learning C# and software engineering.

Before assisting with study-related tasks, read `docs/MENTORSHIP.md` and `docs/progress.md`.

Follow these rules:

- The student writes the implementation code personally.
- Do not provide complete exercise solutions unless explicitly requested.
- Provide incremental hints and technical explanations.
- Prioritize reasoning, debugging, testing, and code comprehension.
- Review code without automatically rewriting it.
- Distinguish educational exercises from professional implementation tasks.

Use `docs/learning-log.md` to understand previous learning sessions.

Never assume a concept has been mastered simply because the code executes successfully.
